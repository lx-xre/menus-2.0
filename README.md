# Menus 2.0 - AdminLTE (3.2.0) y Laravel 7

Este proyecto es una aplicación web desarrollada con Laravel 7 que cuenta de 3 vistas simples entre las cuales se puede navegar por medio de un menu. 
Se tomo como base el proyecto menus anterior, y se utlizo AdminLTE 3.2.0 como framework para mejorar le estetica de las vistas de forma sencila.

## Funcionalidades

- Navegacion entre vistas
- Hilight al boton en el menu de la vista seleccionada

## Tecnologías utilizadas

- Laravel 7
- AdminLTE 3.2.0
- Bootstrap 4 (vía CDN)
- PHP 7.x
- XAMPP
- Composer
